# ✨ Animated Sign-In

A creative and visually engaging **sign-in page** built with HTML, CSS, and JavaScript — featuring smooth animations and a unique glowing **show-password** button that adds a delightful touch to the user experience.

## ✨ Features

- 🔐 **Animated sign-in form** with polished transitions
- 💡 **Glow effect** on the show-password toggle button
- 👁️ **Password visibility toggle** with smooth visual feedback
- 🎨 Fully styled with custom CSS animations

## 🛠️ Built With

- **HTML5** — Page structure
- **CSS3** — Animations, transitions, and glow effects
- **JavaScript** — Password toggle interactivity

## 📁 Project Structure

```
animated-signin/
├── index.html   # Sign-in page markup
├── style.css    # Animations and styling
├── script.js    # Show/hide password logic
└── README.md    # Project documentation
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/illusionoftalha/animated-signin.git
   ```
2. Open `index.html` in your browser — no build step needed.

## 💡 Highlights

The standout feature of this project is the **show-password button** — when clicked, it not only reveals the password but also emits a soft glow, making the interaction feel polished and modern. The animations throughout are smooth and seamless, ensuring a pleasant user experience.
